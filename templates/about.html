About & System Architecture

Technical documentation, machine learning design, and GTU grading standards alignment.

Project Overview

The AI-Based GTU Student Exam Readiness & Performance Prediction System provides Gujarat Technological University (GTU) engineering students with early data-driven performance assessments before final GTU theory examinations.

Built using scikit-learn machine learning classifiers, Flask backend APIs, and an interactive SaaS frontend, the system estimates pass probabilities, official GTU grades (`AA` to `FF`), performance risk categories, and generates domain-specific revision guidance.

Official GTU Grading Scale Alignment

FF < 35% Fail / Backlog Fail (At Risk)

Machine Learning Pipeline Architecture

The platform uses a single unified multi-class classifier pipeline trained on 7,000 realistic GTU student records:

  • Categorical Preprocessing: `OneHotEncoder(handle_unknown='ignore')` for Department, Semester, Subject, and Assessment Stage.
  • Numerical Preprocessing: `SimpleImputer(strategy='constant', fill_value=-1.0)` and `StandardScaler()` for Attendance, SPI, Study Hours, Backlogs, Mid-1, and Mid-2.
  • Classifier Selection: Trained and evaluated `RandomForestClassifier`, `ExtraTreesClassifier`, and `HistGradientBoostingClassifier`. Selected `HistGradientBoostingClassifier` based on cross-validated F1 score (~69.86% multi-class accuracy across 8 fine-grained GTU grades).
